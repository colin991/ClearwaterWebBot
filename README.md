# Clearwater Discord Bot

Blank Discord bot for a rebuild. It logs in and clears slash commands. No automations or commands run yet.

## Setup

1. Copy `.env.example` to `.env` on the bot host.
2. Set `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`, and `DISCORD_GUILD_ID`.
3. Run `npm install` and `npm start`.

On Spark/Apollo, keep the locked startup command. Restart the host after pushing to `main`.
