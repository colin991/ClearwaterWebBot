Clearwater Phone
================

In-game overlay for Clearwater Roleplay (ER:LC).

How to install
--------------
1. Download ClearwaterPhone.zip from Clearwater Internet.
2. Extract the zip anywhere (Desktop is fine).
3. Double-click ClearwaterPhone-Launch.bat
4. The first run downloads a one-time runtime (~100 MB), then opens the phone.
5. Press F8 while playing to hide or show the overlay. Drag the status bar to move it.

Apps
----
Wallet, Marketplace, Find My, Mail, Messages, Maps

Notes
-----
- Does not inject into Roblox — it floats above your game.
- Windows 10/11 (64-bit). Requires internet for the first launch only.
- Re-download from Clearwater Internet whenever we ship updates.
